# Replit preview

The public portfolio is static HTML, CSS, and JavaScript. The Start application workflow serves it on port 5000.

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

The public catalog lives in `projects.json`. The project editor is available on the deployed portfolio and through the local launcher. It adds entries with optimized cover and gallery images. Keep asset URLs relative for GitHub Pages. The Artisan Coffee and Dream of Nature Safari websites are independent redesigns.

The contact form uses FormSubmit. See [the portfolio README](README.md) for the editor and Pages deployment steps.
